# Contributing to Party Games

Before starting, read the project documentation:

- [`Git Workflow`](docs/git-workflow.md) — branches, commits, rebases, Pull Requests, and the development workflow.
- [`Coding Guidelines`](docs/coding-guidelines.md) — coding conventions used throughout the project.
- [`Learning Resources`](docs/learning-resources.md) — recommended resources for learning the technologies used in the project.

## Before Opening a Pull Request

Make sure your changes:

- follow the project coding guidelines;
- are focused on the task you are working on;
- are formatted and pass linting;
- build successfully.

For the complete development process, follow the [`Git Workflow`](docs/git-workflow.md).

## Need Help?

If you get stuck, check the documentation and [`Learning Resources`](docs/learning-resources.md).

If you still need help, ask questions and explain what you tried and what happened.
